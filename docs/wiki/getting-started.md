# Getting started

OctaneRPG is becoming a standalone game. The Discord version is now read-only: you can still look at
profiles, garages and leaderboards, but you can no longer race, buy or upgrade there.

- **Play:** follow <https://octanerpg.com/>. Alpha testing runs through the [Discord](https://discord.octanerpg.com/).
- **Fresh start:** the new game starts from zero for everyone. Progress from the Discord version does not carry over.
- **Founder rewards:** if you played the Discord version, your profile earns Founder rewards (a title and a badge)
  in the new game once you link your Discord account.
