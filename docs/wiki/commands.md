# Bot commands

The Discord bot is read-only. These commands remain; none of them change a profile.

| Command | Description |
|---------|-------------|
| `/profile [user]` | View player profiles |
| `/stats [user]` | View player stats |
| `/garage` | View your stored cars and their stats |
| `/inventory` | Display your inventory |
| `/cooldowns` | Check reward cooldowns |
| `/challenges` | View challenge progress |
| `/leaderboard` | View the player leaderboard |
| `/top` | View top guilds |
| `/guild` | View guild information and settings |
| `/practice` | Practice race against another player |
| `/settings` | Edit settings for your guild (server admins) |
| `/help` | Display help |
| `/info` | Bot information |
| `/start` | Find out where OctaneRPG went |
