# Discord bot

The Discord bot is a **read-only viewer** of the game. Nothing it does changes your profile. Gameplay has moved to the standalone game.

| Command | Description |
|---|---|
| `/profile [user]` | View a player's profile |
| `/stats [user]` | View a player's stats |
| `/garage` | View stored cars and their stats |
| `/inventory` | Display an inventory |
| `/cooldowns` | Check reward cooldowns |
| `/challenges` | View challenge progress |
| `/leaderboard` | View the player leaderboard |
| `/top` | View top guilds |
| `/guild` | View guild information and settings |
| `/practice` | Free practice race against another player (no rewards) |
| `/settings` | Server admins: level-up announcements and allowed channels |
| `/help` | Display help |
| `/info` | Bot information |
| `/start` | Find out where OctaneRPG went |
