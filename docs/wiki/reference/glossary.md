# Glossary

| Term | Meaning |
|---|---|
| **Aurora Hills** | The city the game is set in |
| **Bay 3** | Your garage bay at Number Seven Motors |
| **Chibi GP** | The idle racing ladder in your phone |
| **Class** | D, C, B, A or S, from your car's [PI](../gameplay/performance-and-classes.md) |
| **Crew** | A player-made group. See [Crews](../gameplay/crews.md). |
| **Dyno** | Shows a car's predicted ET and what each part will save |
| **ET** | Elapsed time over 400 m |
| **Heat** | Police attention from crime and street racing |
| **Moshi Mobile** | The in-game phone |
| **OTP** | [Own The Pavement](../factions/own-the-pavement.md) |
| **PI** | Performance Index |
| **Podium Points** | Currency for gear draws |
| **Red light** | Leaving before green. An automatic loss. |
| **Respect** | Per-crew reputation with TEF or OTP |
| **Sponsor Deal** | Coin-funded upgrade for gear draw odds |
| **TEF** | [The Elite Few](../factions/the-elite-few.md) |
| **Usable** | A junkyard part you can install |
| **Zeroyon** | The local drag strip |
