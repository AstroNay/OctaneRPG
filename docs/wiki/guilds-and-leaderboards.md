# Guilds and leaderboards

A guild is a Discord server. The bot ranks players and servers:

- `/leaderboard` shows the player leaderboard, globally or for the server.
- `/top` ranks guilds by XP, coins or car meet attendance.
- `/guild` shows information about the current server.

Server admins can use `/settings` to choose level-up announcements and the channels the bot may reply in.
