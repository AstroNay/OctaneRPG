# Districts and map

The town is built from screen-sized **districts**. Walk off the edge through a gap in the fence and the next district loads. Arrows bob at exits and show the destination name.

## Map

Columns run west to east, rows south to north.

| | West | Middle | East |
|---|---|---|---|
| **North** | | Shrine | |
| **Middle** | Harbor | Garage | Junkyard |
| **South** | Beach | Home | Race |

## Districts

| District | What's there | Open? |
|---|---|---|
| **Home** | Aurora Terrace, your apartment | Yes |
| **Garage** | Number Seven Motors, gear vending machine | Yes |
| **Junkyard** | Junkyard, scrapyard, storage, market, lottery machine, shrine building | Yes |
| **Race** | Zeroyon drag strip entrance | Yes |
| **Harbor** | The docks | Not yet reachable |
| **Beach** | | Not yet reachable |
| **Shrine** | The shrine building (currently in the Junkyard district) | Not yet reachable |

## Building interactions

Walk to a building's south face (north for the drag strip) and press **E**. Buildings you can enter include the store, garage, junkyard, dealership, shrine, market, job board, fuel station, back alley, car meet, scrapyard and the two machines.

## Markers

Turn world markers on in Settings: entrances cyan, storage purple, NPCs amber, vehicles green, fuel yellow.
