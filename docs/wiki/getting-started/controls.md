# Controls

Open **Esc → Settings → Controls** to rebind keys. Every action has two keyboard slots, so you can keep a second binding.

| Action | Default | Notes |
|---|---|---|
| Move | Arrow keys (plus a second bindable set) | Arrow keys are always active |
| Sprint | Rebindable | |
| Interact | **E** | Talk to people, enter buildings, advance dialogue |
| Vehicle | **V** | Get in or out of a car |
| Phone | **Tab** | Opens independently of menus; you can keep walking |
| Inventory | **I** | Your bag |
| Pause | **Esc** | Pause menu, Settings, Report a bug |
| Launch | **Space** or left mouse | Drag-strip launch |

Controller support is planned for the beta.

## Other settings

- **Audio:** Master, Music and SFX sliders.
- **Graphics:** resolution and Day/Night UI theme.
- **World markers:** show or hide the coloured markers over interactables (entrances cyan, storage purple, NPCs amber, vehicles green, fuel yellow).
- **Control hints:** on-screen key prompts.
- **Account:** username, link Discord or Google. See [Accounts and Founders](accounts-and-founders.md).

## Found a bug?

Press **Esc → Report a bug**. It sends your description with the build version and a short log.
